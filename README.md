# MCSV Workspace — руководство пользователя

**Версия 2.2.0 · Расширение для LibreOffice Calc**

MCSV Workspace позволяет работать с несколькими CSV как с одной таблицей: каждый CSV
открывается на отдельном листе Calc. Файл `.mcsv` хранит список листов и их настройки,
а сами данные лежат рядом, в скрытой папке `.mcsv`.

У расширения нет собственного меню. Используются обычные команды Calc: открытие,
сохранение, вкладки листов и кнопка «+».

> Главное: сохраняйте изменения через Cmd+S / Ctrl+S и переносите папку набора целиком.
> Формат предназначен для данных: оформление и формулы в нём не сохраняются.

## 1. Установка

1. Скачайте файл `csvworkspace-mcsv-2.2.0.oxt`.
2. Откройте его с помощью LibreOffice и подтвердите установку расширения.
3. Если установлена предыдущая версия, подтвердите её обновление.
4. Полностью закройте LibreOffice и запустите снова. На macOS используйте **Cmd+Q**:
   закрытия одного окна недостаточно.

После установки в списке форматов окна «Сохранить как…» должен появиться
**MCSV Workspace (.mcsv)**.

## 2. Создание нового набора

1. Создайте новую таблицу в Calc или откройте таблицу с нужными данными.
2. Выберите **Файл → Сохранить как…**.
3. Укажите имя, например `Проект.mcsv`, и папку назначения.
4. В списке типов файлов выберите **MCSV Workspace (.mcsv)**.
5. Нажмите «Сохранить».
6. В начальном диалоге выберите общий разделитель CSV. Если специальных требований
   нет, оставьте предложенное значение `;`.
7. Дождитесь завершения сохранения.

**Просто дописать `.mcsv` к имени недостаточно — нужно выбрать соответствующий тип файла.**

Расширение создаст папку `Проект` и переключит открытый документ на `Проект/Проект.mcsv`.
Внутри папки будут конфигурация, CSV и резервные копии. Не закрывайте LibreOffice,
пока первое сохранение не завершилось.

Если исходная таблица содержит формулы или оформление, сохраните её оригинал отдельно
в формате ODS. В MCSV попадут значения ячеек со всех листов.

## 3. Открытие набора

В Calc выберите **Файл → Открыть…** и укажите `.mcsv`. Все листы набора откроются
в одном документе, а CSV будут разбиты на столбцы по своим разделителям.

Можно открывать `.mcsv` двойным щелчком, если в системе этот формат связан с LibreOffice.
На macOS это настраивается через сведения о файле в Finder: **Открывать в программе →
LibreOffice → Изменить всё…**.

Пустой `.mcsv` открывается как чистый набор с одним листом. Повреждённый непустой файл
не считается пустым: вместо его сброса расширение сообщает об ошибке.

Открывайте именно `.mcsv`, чтобы работать со всем набором. Открытие отдельного `.csv`
открывает только этот CSV.

## 4. Работа с листами

### Добавить лист

Нажмите стандартный **«+»** рядом с вкладками. Новый лист появится сразу, без диалога.
Он получит разделитель набора по умолчанию.

### Переименовать, переместить или удалить лист

Используйте обычные средства Calc: контекстное меню вкладки и перемещение вкладок.
Название CSV формируется из названия листа при сохранении. Символы, недопустимые
в имени файла, заменяются автоматически.

### Сохранить изменения

Нажмите **Cmd+S** на macOS или **Ctrl+S** на Windows/Linux.
Одновременно сохраняются значения ячеек, новые и удалённые листы, названия и порядок вкладок.

Нажатие «+» само по себе ничего не записывает на диск. Если закрыть документ и выбрать
«Не сохранять», изменения после последнего сохранения будут отменены.

## 5. Выбор разделителя

Разделитель определяет, каким символом отделены столбцы внутри CSV: например, `;`, `,`
или табуляцией. В Calc данные всё равно отображаются обычными ячейками.

При создании набора разделитель выбирается один раз. Для повседневной работы менять
его при добавлении каждого листа не нужно.

Чтобы изменить настройки:

1. Откройте **Файл → Свойства → Пользовательские свойства**.
2. Найдите нужное свойство и измените его значение, сохранив название свойства.
3. Подтвердите изменения и сохраните документ через Cmd+S / Ctrl+S.

| Свойство | Что меняет |
| --- | --- |
| `MCSV: разделитель новых листов` | Разделитель по умолчанию для новых листов |
| `MCSV: разделитель листа Товары` | Разделитель существующего листа «Товары» |

Допустимы `;`, `,`, `|`, `TAB` для табуляции или другой разрешённый одиночный символ.
Для нового листа отдельное свойство появляется после его первого сохранения.
Изменение общего значения не меняет разделители уже сохранённых листов.

## 6. Где хранятся файлы

Для набора с именем «Проект» используются следующие пути внутри его папки:

| Путь | Содержимое |
| --- | --- |
| `Проект.mcsv` | Конфигурация: список листов и настройки |
| `.mcsv/Проект.mcsv/` | CSV листов, например `Товары.csv` и `Контакты.csv` |
| `.mcsv/.backups/Проект.mcsv/` | Резервные ZIP-копии |

`.mcsv` — скрытая папка. Не удаляйте её: в ней находятся данные, а не временный кеш.
На macOS скрытые файлы можно показать в Finder сочетанием **Cmd+Shift+.**.

В одной папке набора можно хранить несколько конфигураций. Например, после сохранения
`Склад.mcsv` рядом с `Проект.mcsv` его CSV будут находиться в `.mcsv/Склад.mcsv/`.
У каждой конфигурации собственные резервные копии.

## 7. Перенос, копирование и переименование

### Перенести набор или отправить другому человеку

1. Сохраните документ и закройте его.
2. Скопируйте или переместите **всю папку набора**, включая скрытую `.mcsv`.
3. При отправке удобно упаковать всю папку в ZIP. Убедитесь, что скрытая папка включена.
4. На другом компьютере установите расширение, распакуйте архив и откройте `.mcsv`.

Один файл `.mcsv` без папки данных не содержит самих таблиц.

### Создать независимую копию

Откройте набор и используйте **Файл → Сохранить как…** под новым именем.
Не дублируйте только файл конфигурации: такая копия может ссылаться на прежние CSV.

### Переименовать конфигурацию

После сохранения набора в версии 2.2.0 закройте документ и переименуйте `.mcsv`
внутри той же папки. Расширение запоминает имя каталога данных, поэтому CSV останутся
доступны. Каталог данных вручную переименовывать не нужно.

## 8. Резервные копии и восстановление

Расширение хранит **до трёх последних состояний перед изменением** в ZIP-архивах.
Сохранение без изменений не создаёт новый бэкап. При успешном сохранении более старые
копии удаляются автоматически.

Чтобы восстановить данные:

1. Закройте документ. Если в нём есть нужные несохранённые правки, сначала сохраните
   их отдельно через «Сохранить как…».
2. Откройте `.mcsv/.backups/<имя конфигурации>/` внутри папки набора.
3. Выберите архив с нужным состоянием.
4. Распакуйте его в **отдельную пустую папку**.
5. Откройте находящийся там `.mcsv` и проверьте данные.

Не распаковывайте архив поверх рабочего набора. ZIP содержит конфигурацию и её CSV,
но не посторонние файлы, которые вы могли вручную положить рядом.

Резервные копии находятся на том же диске. Для защиты от потери диска сохраняйте
дополнительную копию всей папки в другом месте.
