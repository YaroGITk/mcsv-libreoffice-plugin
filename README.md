# MCSV Workspace — руководство пользователя

Расширение для LibreOffice, добавляющее формат **MCSV Workspace (.mcsv)** — набор CSV-листов с общей конфигурацией.

## Установка

1. Скачайте файл плагина: расширения для LibreOffice обычно имеют формат `.oxt`.
2. Откройте LibreOffice: запустите главную программу или любое приложение (например, Writer или Calc).
3. Откройте Управление расширениями: в верхнем меню выберите **Сервис → Управление расширениями** (или нажмите **Ctrl + Alt + E**).
4. Добавьте плагин: в открывшемся окне нажмите кнопку **«Добавить»**, выберите ваш скачанный `.oxt` файл и нажмите **«Открыть»**.
5. Подтвердите установку: если программа попросит, примите лицензионное соглашение.
6. Перезапустите программу: закройте и снова откройте LibreOffice, чтобы плагин начал работу.

## Создание нового набора

1. Создать/открыть таблицу — новая таблица в Calc или открыть нужную таблицу.
2. Сохранить как MCSV — **Файл → Сохранить как…**.
3. Указать имя — например `Проект.mcsv`.
4. Выбрать тип — **MCSV Workspace (.mcsv)**.
5. Нажать — **Сохранить**.
6. Выбрать разделитель — в начальном диалоге выбрать общий разделитель CSV; если нет требований — оставить `;`.

## Открытие набора

* Открыть набор — **Файл → Открыть…** → указать `.mcsv`.
* Открыть двойным щелчком — привязать `.mcsv` к LibreOffice; на macOS: Finder → сведения о файле → **Открывать в программе → LibreOffice → Изменить всё…**.

## Работа с листами

* Добавить лист — нажать **«+»** рядом с вкладками.
* Переименовать/переместить/удалить лист — контекстное меню вкладки или перетаскивание вкладок.
* Сохранить изменения — **Cmd+S** на macOS / **Ctrl+S** на Windows/Linux.
* Отменить изменения после последнего сохранения — закрыть документ → выбрать **«Не сохранять»**.

## Где хранятся файлы

Для набора с именем `Проект` используются следующие пути внутри его папки:

| Путь | Содержимое |
| --- | --- |
| `проект/Проект.mcsv` | Конфигурация: список листов и настройки |
| `проект/.mcsv/Проект/` | CSV листов, например `Товары.csv` и `Контакты.csv` |
| `проект/.mcsv/.backups/Проект/*.zip` | Резервные ZIP-копии |

* Не удалять — папку `.mcsv`.
* Несколько конфигураций — рядом можно хранить `/проект/Склад.mcsv`; его CSV будут в `/проект/.mcsv/Склад.mcsv/`, у каждой конфигурации свои бэкапы.

## Перенос, копирование, переименование

* Перенести/отправить набор — сохранить документ → закрыть → скопировать/переместить **всю папку набора**, включая скрытую `.mcsv`.
* Отправить другому человеку — упаковать всю папку в ZIP, включая скрытую `.mcsv`; на другом компьютере установить расширение, распаковать архив, открыть `.mcsv`.
