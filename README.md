# MCSV Workspace — руководство пользователя

Расширение для LibreOffice Calc, добавляющее формат **MCSV Workspace (.mcsv)**.
Один набор объединяет несколько CSV-файлов: каждый открывается на отдельном листе.

## Установка

1. Скачайте файл расширения **`csvworkspace-mcsv`**.
2. Запустите LibreOffice.
3. Выберите **Сервис → Управление расширениями…**.
4. Нажмите **Добавить…**, выберите скачанный `.oxt` и нажмите **Открыть**.
5. Подтвердите установку.
6. Полностью закройте LibreOffice и запустите снова.

## Создание нового набора

1. Создайте новую таблицу в Calc или откройте существующую.
2. Выберите **Файл → Сохранить как…**.
3. Укажите папку и имя файла, например `Проект.mcsv`.
4. В поле **Тип файла** выберите **MCSV Workspace (.mcsv)**.
5. Нажмите **Сохранить**.
6. Выберите разделитель CSV. Если особых требований нет, оставьте `;`.
7. Дождитесь завершения сохранения и автоматического переоткрытия документа.

## Открытие набора

Выберите **Файл → Открыть…** и укажите файл `.mcsv` внутри папки набора.
Все CSV откроются на отдельных листах одного документа.

Если `.mcsv` связан с LibreOffice в настройках операционной системы, его также
можно открыть двойным щелчком.

## Работа с листами

- **Добавить лист:** нажмите **«+»** рядом с вкладками. Новый лист использует разделитель набора.
- **Переименовать или удалить лист:** нажмите правой кнопкой на вкладку и выберите нужное действие.
- **Переместить лист:** перетащите его вкладку в нужное место.
- **Сохранить изменения:** нажмите **Cmd+S** на macOS или **Ctrl+S** на Windows/Linux.
- **Отменить несохранённые изменения:** закройте документ и выберите **Не сохранять**.

## Где хранятся файлы

После создания набора `Проект.mcsv` в выбранном месте появится папка `Проект`:

| Путь | Содержимое |
| --- | --- |
| `Проект/Проект.mcsv` | Конфигурация: список листов и настройки |
| `Проект/.mcsv/Проект.mcsv/` | CSV-файлы листов, например `Товары.csv` |
| `Проект/.mcsv/.backups/Проект.mcsv/` | До трёх резервных ZIP-копий |

В последних двух строках `Проект.mcsv` — **имя каталога**, а не файла.
Скрытая папка `.mcsv` содержит данные: удалять её нельзя.

Чтобы создать три независимых набора, при сохранении каждого выбирайте одну общую
родительскую папку. Для каждого набора появится свой подкаталог. Если сохранить новую
конфигурацию внутри уже существующей папки набора, она будет использовать эту папку,
но получит отдельный каталог CSV.

## Перенос, копирование и переименование

- **Перенести набор:** сохраните документ, закройте его и перенесите **всю папку набора**,
  включая скрытую `.mcsv`. Одного файла конфигурации недостаточно.
- **Отправить набор:** упакуйте всю папку в ZIP, включая скрытые файлы. Получателю нужно
  установить расширение, распаковать архив и открыть `.mcsv`.
- **Создать независимую копию:** используйте **Файл → Сохранить как…** под новым именем.
  Не копируйте только файл конфигурации.
- **Переименовать файл конфигурации:** для набора закройте документ и переименуйте `.mcsv` 
  внутри той же папки. Каталог данных вручную переименовывать не нужно.

## Восстановление из резервной копии

Откройте каталог бэкапов, указанный выше. Распакуйте нужный ZIP в **отдельную пустую папку**
и откройте находящийся там `.mcsv`. Не распаковывайте архив поверх рабочего набора.

## Ограничения

CSV сохраняет **значения ячеек**. Формулы превращаются в вычисленные результаты;
цвета, оформление и диаграммы не сохраняются. Если они нужны, храните исходную таблицу
отдельно в формате **ODS**.
